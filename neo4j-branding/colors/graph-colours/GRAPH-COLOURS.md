# Graph Colors

Node colors for Neo4j graph visualizations. **Use in this specific order** — when rendering multiple node labels, assign colors sequentially starting from 1.

These are standalone hex values purpose-built for visual distinction in graph layouts. They do not reference the brand shade palettes.
