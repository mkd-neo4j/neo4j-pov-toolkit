# Dark Theme — Code Highlighting Tokens

Syntax highlighting colors for the Neo4j dark theme (Cypher query language). Each token maps to a shade from the [brand color palettes](../../COLORS.md).

### Palette Summary

| Palette     | Usage                                 | Hex       |
| ----------- | ------------------------------------- | --------- |
| Neutral-40  | Comments (muted, de-emphasized)       | `#959AA1` |
| Marigold-25 | Keywords, keyword literals, operators | `#FFC450` |
| Hibiscus-30 | Labels                                | `#F96746` |
| Baltic-20   | Functions, predicates, procedures     | `#8FE3E8` |
| Forest-20   | String literals                       | `#90CB62` |
| Lavender-20 | Number/boolean literals, param values | `#CCB4FF` |
| Hibiscus-20 | Properties                            | `#FFAA97` |
