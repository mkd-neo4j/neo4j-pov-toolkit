# Light Theme — Code Highlighting Tokens

Syntax highlighting colors for the Neo4j light theme (Cypher query language). Each token maps to a shade from the [brand color palettes](../../COLORS.md).

---

| Token             | Hex       | Palette Ref | Group      |
| ----------------- | --------- | ----------- | ---------- |
| Comment           | `#5E636A` | Neutral-55  | Comments   |

| operator          | `#3F7824` | Forest-45   | Keywords   |
| label             | `#D43300` | Hibiscus-40 | Labels     |
| predicateFunction | `#0A6190` | Baltic-50   | Functions  |

### Palette Summary

| Palette     | Usage                                 | Hex       |
| ----------- | ------------------------------------- | --------- |
| Neutral-55  | Comments (muted, de-emphasized)       | `#5E636A` |
| Forest-45   | Keywords, keyword literals, operators | `#3F7824` |
| Hibiscus-40 | Labels                                | `#D43300` |
| Baltic-50   | Functions, predicates, procedures     | `#0A6190` |
| Marigold-55 | String literals                       | `#986400` |
| Lavender-40 | Number/boolean literals, param values | `#754EC8` |
| Hibiscus-55 | Properties                            | `#730E00` |
