# Typography

Typography creates hierarchies and extends the brand presence.

## Font Stack

| Font        | Role                                   | Source Files            |
| ----------- | -------------------------------------- | ----------------------- |
| Public Sans | Workhorse font for all general use     | `../fonts/PublicSans-*` |
| Syne Neo    | Reserved for callout and headline text | `../fonts/SyneNeo-*`    |

---

## Public Sans

Public Sans is the main typeface for the Neo4j brand. **Regular** and **Medium** are the two primary weights used in design communications. Other weights allow for a greater range of emphasis when needed.

### Guidelines

**Do:**

- Use Public Sans for most use cases, especially body, caption, and subheading text
- Use weights in **Regular** and **Medium**

**Caution:**

- Sparingly use weights in Thin, ExtraLight, Light, and Bold

---

## Syne Neo

Syne is intended to be used at large sizes for titles, headings, pull-quotes, and other eye-catching elements.

The shifts within its stroke widths create a sense of playfulness and dynamism, mirroring the flexible node shapes throughout the brand system.

### Guidelines

**Do:**

- Use Syne Neo for large H1 or title headlines
- Use **Medium** and **SemiBold** weights for headlines
- Use **Bold** weight for eyebrows

**Don't:**

- Use Syne Neo for body or subheading text
- Use Regular or ExtraBold weights in any instances

### Syne Neo vs Syne

Syne Neo is unavailable in the Google Suite and cannot be used in Google Docs or Slides. In these environments, use **Syne** instead.

Some of Syne's quirks can lead to confusion. Keep the following in mind:

- **Update Syne number settings** in your software to "Proportional Upper Case" (see below for details)
- **Don't** use Syne's default settings as it uses oldstyle numerals which offset the baseline of numbers and can imply unintentional numerical meaning like superscripts
- **Don't** use Syne to spell out any words with the letter "j" (including "Neo4j") as it is indistinguishable from "i" — use Public Sans instead, or use a vector version of Neo4j provided in the Google Slide template

## Combining Type

Use the different typefaces together to create clear hierarchy:

| Element    | Font        | Weight          |
| ---------- | ----------- | --------------- |
| Eyebrow    | Syne Neo    | Bold            |
| Headline   | Syne Neo    | Medium/SemiBold |
| Subheading | Public Sans | Medium          |
| Body       | Public Sans | Regular         |

### Best Practices

**Do:**

- Use Syne and Public Sans in the weights and styles described above
- Use Syne Neo sparingly and for short phrases to emphasize type in large moments

**Don't:**

- Use all caps in Syne Neo for headlines
- Use Syne Neo for long headlines as it starts to lose the quality of a bold statement
- Use Syne Neo and Public Sans in the same sentences
- Use unapproved weights such as ExtraBold and Regular for Syne in the Google Suite

**Caution:**

- All caps and italics should be used sparingly in Public Sans
- Avoid using too much italics as it can be confusing and misleading
- Don't flush right unless the design absolutely requires it
- Watch out for widows or orphans
